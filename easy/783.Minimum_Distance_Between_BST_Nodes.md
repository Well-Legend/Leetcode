# 783. Minimum Distance Between BST Nodes

**Link**: https://leetcode.com/problems/minimum-distance-between-bst-nodes/  
**Tags**: Tree, Depth-First Search, Breadth-First Search, Binary Search Tree, Binary Tree  
**Difficulty**: Easy

## 題目解釋
給定一棵 binary search tree 的根節點 `root`，請回傳樹中任兩個不同節點值之間的最小差值。  
因為 BST 的 inorder traversal 會得到遞增序列，所以只要比較排序後相鄰節點的差值即可。

## 限制與條件
- 樹中節點數量在 `[2, 100]`
- `0 <= Node.val <= 10^5`

## 解法思路
### 思考過程
你的程式碼和第 530 題一樣，利用 BST 的 inorder traversal 特性：
1. 遞迴走訪左子樹，取得較小的節點。  
2. 用 `prev` 保存上一個 inorder 走訪到的節點。  
3. 若 `prev` 不為 `nullptr`，就計算目前節點與前一個節點的差值。  
4. 用這個差值更新 `minimum`。  
5. 將 `prev` 改成目前節點，繼續走訪右子樹。  

中序走訪得到的節點值是遞增的，因此相鄰節點差值中的最小值就是答案。

### 解法：Inorder Traversal with Adjacent Difference
> [!IMPORTANT]
> 思路：把 BST 視為已排序序列，只比較 inorder 中相鄰節點的差。

### 複雜度分析
| 維度 | 複雜度 | 說明 |
| --- | --- | --- |
| 時間複雜度 | O(n) | 每個節點都會被走訪一次。 |
| 空間複雜度 | O(h) | 來自遞迴堆疊，`h` 為樹高。 |

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
private:
    int minimum = INT_MAX;
    TreeNode* prev = nullptr;
    void Inorder(TreeNode* node){
        if(!node){
            return;
        }
        Inorder(node->left);
        if(prev){
            minimum = min(minimum, node->val - prev->val);
        }
        prev = node;
        Inorder(node->right);
    }

public:
    int minDiffInBST(TreeNode* root) {
        Inorder(root);
        return minimum;        
    }
};
```
