# 637. Average of Levels in Binary Tree

**Link**: https://leetcode.com/problems/average-of-levels-in-binary-tree/  
**Tags**: Tree, Depth-First Search, Breadth-First Search, Binary Tree  
**Difficulty**: Easy

## 題目解釋
給定一棵 non-empty binary tree 的根節點 `root`，請回傳每一層節點值的平均值。  
答案中第 `i` 個數值代表第 `i` 層所有節點值的平均。

## 限制與條件
- 樹中節點數量在 `[1, 10^4]`
- `-2^31 <= Node.val <= 2^31 - 1`

## 解法思路
### 思考過程
你的程式碼使用 BFS 逐層走訪，並透過 `tail` 判斷目前層是否結束：
1. 若 `root` 為 `nullptr`，直接回傳空陣列。  
2. 將根節點放入 queue，並讓 `tail` 指向目前層的最後一個節點。  
3. 走訪節點時，把節點值累加到 `sum`，並用 `num` 計算這一層的節點數。  
4. 若目前節點等於 `tail`，代表該層已走完。  
5. 將 `sum / num` 加入答案，並重置 `sum`、`num`。  
6. 把 `tail` 更新為 queue 中下一層的最後一個節點。  

這樣每一層結束時就能得到該層平均值。

### 解法：BFS with Level Sum
> [!IMPORTANT]
> 思路：用 queue 做 level order traversal，並在每層結束時計算平均值。

### 複雜度分析
| 維度 | 複雜度 | 說明 |
| --- | --- | --- |
| 時間複雜度 | O(n) | 每個節點只會被處理一次。 |
| 空間複雜度 | O(n) | queue 最多可能保存一層節點，答案保存每層平均值。 |

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<double> averageOfLevels(TreeNode* root) {
        queue<TreeNode*> que;
        TreeNode* tail = root;
        que.push(root);
        vector<double> ans;
        double sum=0, num=0;

        if(!root){
            return ans;
        }
        while(!que.empty()){
            root = que.front();
            sum += root->val;
            num++;
            if(root->left){
                que.push(root->left);
            }
            if(root->right){
                que.push(root->right);
            }
            
            if(tail == root){
                sum /= num;
                ans.push_back(sum);
                sum = 0;
                num = 0;
                tail = que.back();
            }
            que.pop();
        }
        return ans;
    }
};
```
