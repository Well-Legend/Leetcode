# 222. Count Complete Tree Nodes

**Link**: https://leetcode.com/problems/count-complete-tree-nodes/  
**Tags**: Tree, Depth-First Search, Binary Search, Binary Tree  
**Difficulty**: Easy

## 題目解釋
給定一棵 complete binary tree 的根節點 `root`，請回傳樹中的節點數量。  
Complete binary tree 的每一層除了最後一層外都會被填滿，最後一層則由左到右填入節點。

## 限制與條件
- 樹中節點數量在 `[0, 5 * 10^4]`
- `0 <= Node.val <= 5 * 10^4`
- 輸入保證是 complete binary tree

## 解法思路
### 思考過程
你的程式碼使用最直接的遞迴計數：
1. 若目前節點為 `nullptr`，代表沒有節點，回傳 `0`。  
2. 否則分別計算左子樹與右子樹的節點數。  
3. 再加上目前節點本身的 `1`。  

雖然題目提供 complete binary tree 的特性可以做更進階的最佳化，但這份程式碼的邏輯清楚，會正確走訪並計算所有節點。

### 解法：Recursive Tree Counting
> [!IMPORTANT]
> 思路：節點總數等於左子樹節點數、右子樹節點數，再加上根節點本身。

### 複雜度分析
| 維度 | 複雜度 | 說明 |
| --- | --- | --- |
| 時間複雜度 | O(n) | 每個節點都會被走訪一次。 |
| 空間複雜度 | O(h) | 來自遞迴堆疊，`h` 為樹高。 |

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int countNodes(TreeNode* root) {
        if(!root){
            return 0;
        }
        return countNodes(root->left) + countNodes(root->right) + 1;
    }
};
```
