# 530. Minimum Absolute Difference in BST

**Link**: https://leetcode.com/problems/minimum-absolute-difference-in-bst/  
**Tags**: Tree, Depth-First Search, Breadth-First Search, Binary Search Tree, Binary Tree  
**Difficulty**: Easy

## 題目解釋
給定一棵 binary search tree 的根節點 `root`，請找出任兩個不同節點值之間的最小絕對差。  
因為 BST 的 inorder traversal 會得到遞增序列，所以最小差值一定會出現在 inorder 序列中相鄰的兩個節點之間。

## 限制與條件
- 樹中節點數量在 `[2, 10^4]`
- `0 <= Node.val <= 10^5`

## 解法思路
### 思考過程
你的程式碼使用 inorder traversal 依序取得 BST 節點：
1. 先走訪左子樹，確保節點值由小到大出現。  
2. 使用 `prev` 記錄上一個走訪到的節點。  
3. 若 `prev` 存在，就用 `node->val - prev->val` 更新目前最小差值 `minimum`。  
4. 將 `prev` 更新為目前節點，再繼續走訪右子樹。  

由於 inorder 序列已經排序，任兩點的最小差只需要比較相鄰節點，不需要枚舉所有節點組合。

### 解法：Inorder Traversal with Previous Node
> [!IMPORTANT]
> 思路：BST 中序走訪是遞增序列，最小絕對差只會出現在相鄰節點之間。

### 複雜度分析
| 維度 | 複雜度 | 說明 |
| --- | --- | --- |
| 時間複雜度 | O(n) | 每個節點都會被走訪一次。 |
| 空間複雜度 | O(h) | 來自遞迴堆疊，`h` 為樹高。 |

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
private:
    int minimum = INT_MAX;
    TreeNode* prev = nullptr;
    void Inorder(TreeNode* node){
        if(!node){
            return;
        }
        Inorder(node->left);
        if(prev){
            minimum = min(minimum, node->val - prev->val);
        }
        prev = node;
        Inorder(node->right);
    }

public:
    int getMinimumDifference(TreeNode* root) {
        Inorder(root);
        return minimum;
    }
};
```
