# 236. Lowest Common Ancestor of a Binary Tree

**Link**: https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-tree/  
**Tags**: Tree, Depth-First Search, Binary Tree  
**Difficulty**: Medium

## 題目解釋
給定一棵 binary tree 的根節點 `root`，以及樹中的兩個節點 `p`、`q`，請找出它們的 lowest common ancestor。  
Lowest common ancestor 是同時擁有 `p` 和 `q` 作為後代的最低節點，節點也可以是自己的後代。

## 限制與條件
- 樹中節點數量在 `[2, 10^5]`
- `-10^9 <= Node.val <= 10^9`
- 所有 `Node.val` 互不相同
- `p != q`
- `p` 與 `q` 都存在於樹中

## 解法思路
### 思考過程
你的程式碼使用 DFS 從下往上回傳搜尋結果：
1. 若 `root` 為 `nullptr`，代表這條路沒有找到目標，回傳 `nullptr`。  
2. 若目前節點就是 `p` 或 `q`，回傳目前節點。  
3. 分別往左子樹與右子樹尋找 `p`、`q`。  
4. 若左右子樹都回傳非空，代表 `p` 與 `q` 分別在目前節點兩側，因此目前節點就是 LCA。  
5. 若只有一側非空，代表兩個目標都在同一側，或目前只找到其中一個，直接把非空結果往上回傳。  

因為題目保證 `p` 與 `q` 都存在，所以最後一定會找到正確的共同祖先。

### 解法：Postorder DFS
> [!IMPORTANT]
> 思路：左右子樹各自回報是否找到目標；若兩邊都找到，當前節點就是最低共同祖先。

### 複雜度分析
| 維度 | 複雜度 | 說明 |
| --- | --- | --- |
| 時間複雜度 | O(n) | 最壞情況需要走訪所有節點。 |
| 空間複雜度 | O(h) | 來自遞迴堆疊，`h` 為樹高。 |

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode(int x) : val(x), left(NULL), right(NULL) {}
 * };
 */
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if(root==nullptr || root==p || root==q){
            return root;
        }
        TreeNode* left = lowestCommonAncestor(root->left, p, q);
        TreeNode* right = lowestCommonAncestor(root->right, p, q);

        if(left && right){
            return root;
        }
        if(left){
            return left;
        }
        else{
            return right;
        }
    }
};
```
