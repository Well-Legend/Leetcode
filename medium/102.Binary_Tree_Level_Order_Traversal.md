# 102. Binary Tree Level Order Traversal

**Link**: https://leetcode.com/problems/binary-tree-level-order-traversal/  
**Tags**: Tree, Breadth-First Search, Binary Tree  
**Difficulty**: Medium

## 題目解釋
給定一棵 binary tree 的根節點 `root`，請回傳它的 level order traversal。  
也就是從上到下、同一層由左到右，將每一層的節點值分別放在同一個陣列中。

## 限制與條件
- 樹中節點數量在 `[0, 2000]`
- `-1000 <= Node.val <= 1000`

## 解法思路
### 思考過程
你的程式碼使用 BFS 逐層走訪 binary tree，並透過 `tail` 記錄目前這一層的最後一個節點：
1. 若 `root` 為 `nullptr`，直接回傳空陣列。  
2. 將根節點放入 queue，並讓 `tail` 指向根節點。  
3. 每次取出 queue front，將節點值加入目前層的 `sub_ans`。  
4. 若節點有左、右子節點，就依序放入 queue。  
5. 當目前節點等於 `tail`，代表這一層走完：
   - 將 `sub_ans` 加入答案
   - 清空 `sub_ans`
   - 將 `tail` 更新為 queue 中目前最後一個節點，也就是下一層的尾端  

這樣就能把每一層的值分開記錄。

### 解法：BFS with Level Tail Pointer
> [!IMPORTANT]
> 思路：用 queue 維持 BFS 順序，再用 `tail` 判斷目前層何時結束。

### 複雜度分析
| 維度 | 複雜度 | 說明 |
| --- | --- | --- |
| 時間複雜度 | O(n) | 每個節點只會進出 queue 一次。 |
| 空間複雜度 | O(n) | queue 最多可能存放一層節點，答案陣列也會保存所有節點值。 |

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        TreeNode* tail = root;
        queue<TreeNode*> que;
        vector<vector<int>> ans;
        vector<int> sub_ans;
        if(!root){
            return ans;
        }
        que.push(root);
        while(!que.empty()){
            root = que.front();
            sub_ans.push_back(root->val);
            if(root->left){
                que.push(root->left);
            }
            if(root->right){
                que.push(root->right);
            }
            if(tail == root){
                ans.push_back(sub_ans);
                sub_ans.clear();
                tail = que.back();
            }
            que.pop();
        }
        return ans;
    }
};
```
