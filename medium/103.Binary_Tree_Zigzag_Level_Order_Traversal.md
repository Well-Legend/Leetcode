# 103. Binary Tree Zigzag Level Order Traversal

**Link**: https://leetcode.com/problems/binary-tree-zigzag-level-order-traversal/  
**Tags**: Tree, Breadth-First Search, Binary Tree  
**Difficulty**: Medium

## 題目解釋
給定一棵 binary tree 的根節點 `root`，請回傳它的 zigzag level order traversal。  
走訪順序從第一層左到右，下一層右到左，之後每一層持續交替方向。

## 限制與條件
- 樹中節點數量在 `[0, 2000]`
- `-100 <= Node.val <= 100`

## 解法思路
### 思考過程
你的程式碼以 BFS 逐層走訪，並用 `height` 判斷目前層數是否需要反轉：
1. 若 `root` 為 `nullptr`，直接回傳空陣列。  
2. 使用 queue 儲存待處理節點，並用 `tail` 記錄目前層的最後一個節點。  
3. 每處理一個節點，就先將左右子節點加入 queue，再把目前節點值放進 `sub_ans`。  
4. 當目前節點等於 `tail`，代表該層結束。  
5. 若 `height` 是奇數，將 `sub_ans` 反轉，形成右到左的順序。  
6. 把該層結果加入答案，清空 `sub_ans`，並進入下一層。  

因為 BFS 本身仍然維持左到右加入節點，所以只需要在奇數層反轉當層結果即可。

### 解法：BFS + Reverse Odd Levels
> [!IMPORTANT]
> 思路：用 BFS 取得每一層節點，並依照層數奇偶決定是否反轉該層答案。

### 複雜度分析
| 維度 | 複雜度 | 說明 |
| --- | --- | --- |
| 時間複雜度 | O(n) | 每個節點處理一次，反轉各層總長度合計也是 O(n)。 |
| 空間複雜度 | O(n) | queue 與答案陣列會隨節點數增加。 |

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
        queue<TreeNode*> que;
        vector<vector<int>> ans;
        vector<int> sub_ans;
        if(!root){
            return ans;
        }

        int height=0; 
        TreeNode* tail = root;
        que.push(root);
        while(!que.empty()){
            root = que.front();
            if(root->left){
                que.push(root->left);
            }
            if(root->right){
                que.push(root->right);
            }
            
            sub_ans.push_back(root->val);
            if(root == tail){
                if(height%2 == 1){
                    reverse(sub_ans.begin(), sub_ans.end());
                }
                tail = que.back();
                ans.push_back(sub_ans);
                sub_ans.clear();
                height++;
            }
            que.pop();
        }
        return ans;
    }
};
```
