# 173. Binary Search Tree Iterator

**Link**: https://leetcode.com/problems/binary-search-tree-iterator/  
**Tags**: Stack, Tree, Design, Binary Search Tree, Binary Tree, Iterator  
**Difficulty**: Medium

## 題目解釋
請設計一個 `BSTIterator`，能依照 binary search tree 的 inorder traversal 順序逐一回傳節點值。  
因為 BST 的 inorder traversal 會得到遞增序列，所以每次 `next()` 都要回傳下一個最小值。

## 限制與條件
- 樹中節點數量在 `[1, 10^5]`
- `0 <= Node.val <= 10^6`
- 最多呼叫 `hasNext` 與 `next` 共 `10^5` 次
- 呼叫 `next()` 時保證一定存在下一個節點

## 解法思路
### 思考過程
你的程式碼用 stack 模擬 inorder traversal，避免一開始就把所有節點攤平成陣列：
1. 建構子先呼叫 `pushAll(root)`，把從根節點一路往左的節點都放入 stack。  
2. stack top 永遠會是目前還沒回傳的最小節點。  
3. `next()` 取出 stack top，記錄該節點值。  
4. 若該節點有右子樹，右子樹中最小的節點會是下一批候選，因此呼叫 `pushAll(node->right)`。  
5. `hasNext()` 只要判斷 stack 是否為空。  

這樣每個節點最多被 push、pop 各一次，因此平均每次操作很有效率。

### 解法：Controlled Inorder Traversal with Stack
> [!IMPORTANT]
> 思路：只保留目前 inorder traversal 需要的左鏈，讓 stack top 始終是下一個要回傳的節點。

### 複雜度分析
| 維度 | 複雜度 | 說明 |
| --- | --- | --- |
| 時間複雜度 | O(1) amortized | 每個節點最多進出 stack 一次，攤還到每次 `next()` 為 O(1)。 |
| 空間複雜度 | O(h) | stack 最多保存樹高 `h` 個節點。 |

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class BSTIterator {
private:
    stack<TreeNode*> stk;
    void pushAll(TreeNode* node){
        while(node!=nullptr){
            stk.push(node);
            node = node->left;
        }
    }
public:
    BSTIterator(TreeNode* root) {
        pushAll(root);
    }
    
    int next() {
        TreeNode* node = stk.top();
        stk.pop();
        pushAll(node->right);
        return node->val;
    }
    
    bool hasNext() {
        return !stk.empty();
    }
};

/**
 * Your BSTIterator object will be instantiated and called as such:
 * BSTIterator* obj = new BSTIterator(root);
 * int param_1 = obj->next();
 * bool param_2 = obj->hasNext();
 */
```
