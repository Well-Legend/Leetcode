# 230. Kth Smallest Element in a BST

**Link**: https://leetcode.com/problems/kth-smallest-element-in-a-bst/  
**Tags**: Tree, Depth-First Search, Binary Search Tree, Binary Tree  
**Difficulty**: Medium

## 題目解釋
給定一棵 binary search tree 的根節點 `root`，以及一個整數 `k`，請回傳樹中第 `k` 小的節點值。  
因為 BST 的 inorder traversal 會得到由小到大的順序，所以第 `k` 個 inorder 走訪到的節點就是答案。

## 限制與條件
- 樹中節點數量為 `n`
- `1 <= k <= n <= 10^4`
- `0 <= Node.val <= 10^4`

## 解法思路
### 思考過程
你的程式碼使用 inorder traversal 依序走訪 BST：
1. 先遞迴走訪左子樹，因為左子樹的值都比較小。  
2. 回到目前節點時，將計數器 `idx` 加一。  
3. 若 `idx == k`，代表目前節點就是第 `k` 小的節點，將它的值存入 `ans`。  
4. 接著繼續走訪右子樹。  

BST 的 inorder traversal 會形成遞增序列，因此只要數到第 `k` 個節點即可得到答案。

### 解法：Inorder Traversal Counting
> [!IMPORTANT]
> 思路：利用 BST 中序走訪會由小到大的特性，用計數器找出第 `k` 個節點。

### 複雜度分析
| 維度 | 複雜度 | 說明 |
| --- | --- | --- |
| 時間複雜度 | O(n) | 這份寫法找到答案後仍可能繼續走訪剩餘節點。 |
| 空間複雜度 | O(h) | 來自遞迴堆疊，`h` 為樹高。 |

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
private:
    int idx=0, ans;
    void Inorder(TreeNode* node, int k){
        if(!node){
            return;
        }
        if(node->left){
            Inorder(node->left, k);
        }
        idx++;
        if(idx == k){
            ans = node->val;
        }
        Inorder(node->right, k);
    }
public:
    int kthSmallest(TreeNode* root, int k) {
        Inorder(root, k);
        return ans; 
    }
};
```
