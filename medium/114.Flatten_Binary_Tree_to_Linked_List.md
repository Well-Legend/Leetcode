# 114. Flatten Binary Tree to Linked List

**Link**: https://leetcode.com/problems/flatten-binary-tree-to-linked-list/  
**Tags**: Linked List, Stack, Tree, Depth-First Search, Binary Tree  
**Difficulty**: Medium

## 題目解釋
給定一棵 binary tree 的根節點 `root`，請原地將它攤平成 linked list。  
攤平後每個節點的 `left` 都要是 `nullptr`，`right` 則指向 preorder traversal 中的下一個節點。

## 限制與條件
- 樹中節點數量在 `[0, 2000]`
- `-100 <= Node.val <= 100`

## 解法思路
### 思考過程
你的程式碼使用原地調整指標的方式，讓樹逐步變成 preorder 順序的右鏈：
1. 從 `root` 開始一路沿著 `right` 指標往下處理。  
2. 若目前節點有左子樹，先找到左子樹最右邊的節點 `sub`。  
3. 將目前節點原本的右子樹接到 `sub->right`。  
4. 把目前節點的左子樹移到右邊：`root->right = root->left`。  
5. 將 `root->left` 設成 `nullptr`。  
6. 繼續往新的 `root->right` 前進。  

這等於把每個節點的左子樹插入到右子樹之前，符合 preorder 的根、左、右順序。

### 解法：In-place Preorder Rewiring
> [!IMPORTANT]
> 思路：遇到左子樹時，將原右子樹接到左子樹最右端，再把左子樹搬到右邊。

### 複雜度分析
| 維度 | 複雜度 | 說明 |
| --- | --- | --- |
| 時間複雜度 | O(n) | 每個節點都會被處理，尋找左子樹最右端的總成本在此寫法下最多仍隨節點數線性累積。 |
| 空間複雜度 | O(1) | 只使用常數額外指標，並原地修改樹。 |

```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    void flatten(TreeNode* root) {
        while(root){
            if(root->left){
                TreeNode* sub = root->left;
                while(sub->right){
                    sub = sub->right;
                }
                sub->right = root->right;
                root->right = root->left;
                root->left = nullptr;
            }
            root = root->right;
        }     
    }
};
```
